# Security Policy & Vulnerability Disclosure

RitualDev Lab takes the security of **agentshield-helm** Kubernetes charts and air-gapped VPC manifests seriously.

## Supported Versions

| Chart Version | App Version | Supported | Response Target |
| :--- | :---: | :---: | :---: |
| **1.1.x** | `0.2.2` | Active | Critical & High: < 24 Hours |
| < 1.1.0 | `<= 0.2.1` | End-of-Life | Upgrade to chart 1.1.x |

## Reporting a Vulnerability

Please **do not** open public GitHub issues for undisclosed Kubernetes manifest or NetworkPolicy vulnerabilities.

- **GitHub Private Security Advisory (Preferred)**: [Report a Security Advisory](https://github.com/RitualDev-Lab/agentshield-helm/security/advisories/new)
- **Email**: `security@ritualdev.in` with subject `[SECURITY VULNERABILITY] agentshield-helm`

## Compliance & Control Alignment

- **Status**: SOC 2 Type II & ISO 27001 Control-Mapped Architecture (**Self-Attested Readiness; Formal Independent Audit Planned**).
- **Trust & Control Mapping Portal**: [https://ritualdev.in/trust](https://ritualdev.in/trust)
